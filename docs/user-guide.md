# 使用说明

## 启动

在仓库根目录运行 `python -m http.server 4173`，访问 <http://127.0.0.1:4173/>。不需要安装依赖或构建应用。

## 混淆和还原

在“混淆图像”中选择一张或多张原图、选择预设并生成。每张图片分别显示进度、错误和下载操作；可统一调整整批设置，也可关闭统一设置后逐张调整。生成后可继续调整 JPG 质量，结果会自动更新。还原时选择混淆图即可，不需要预设或其他参数。

预览支持适应窗口、原始像素、缩放和平移。静态图片默认下载 JPG；也可以在高级设置中另存压缩前的 PNG。JPG 质量较低时，程序会尝试增强保护；如果仍无法验证还原，会提示提高质量，但文件仍可下载。透明区域在 JPG 中铺为白色，不保留透明通道。

## 动画与批量

GIF 原图可以搭配静态或 GIF 预设。输出保留原图帧数；使用 GIF 预设时按其播放进度匹配画面，并沿用预设时长与循环方式。静态预设沿用原 GIF 时序。静态原图也可生成 GIF，原始静态文件会嵌入 GIF 供还原。GIF 不使用 JPG 质量设置；输出最长边不超过 384 px，最多 300 帧。

“生成全部混淆图”和“还原全部图像”处理列表中的所有图片。已完成结果可以逐张下载或打包为 ZIP；ZIP 内重名文件会自动编号。单张失败不会阻止其他项目完成。

## 预设和设置

自定义预设保存在当前浏览器站点，刷新后仍可使用；清除站点数据也会删除这些预设。透明背景和原图比例会保留，最长边超过 1536 px 时会先缩小。可拖放图片到上传区，并用方向键切换预设。

常用设置包括 JPG 质量、效果偏向和预设图案细节。静态输出的效果偏向中点对应两种效果的平衡配置，滑块两端保持原有的偏向范围；动画输出默认使用 2 px 图块并偏向预设外观，因逐帧处理时间会更长，可按需调回较大的图块。高级设置位于输出选项中，可控制处理尺寸、载体放大倍数、颜色适配、原图细节保留和预设显示方式。默认按比例调整尺寸：短边目标至少 1024 px，最长边至多 2960 px；极端长图优先限制最长边。手动尺寸上限为 1600 万像素、单边 16384 px，混淆图上限为 3200 万像素。

默认以 8×8 像素分块并放大 2 倍。更细的分块或更高倍率会增加输出大小和处理量。还原尺寸与处理尺寸一致；缩小原图丢失的细节无法恢复。预设默认完整显示，空白区域透明填充；也可选择居中裁切或拉伸。长宽比超过 3:1 的图片会分段匹配和还原。

## 限制

混淆图被社交平台缩放、裁切或重采样后可能无法还原。PNG 导出不会消除编码时已有的误差。JPEG 不支持透明通道；WebP 的耐压缩性尚未验证。
